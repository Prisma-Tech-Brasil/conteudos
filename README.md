# 📚 Livros

### 1. *Eloquent JavaScript* – Marijn Haverbeke  
![Eloquent JavaScript](https://eloquentjavascript.net/img/cover.jpg)  
Livro fundamental de JavaScript moderno.  
📖 [Leia online](https://eloquentjavascript.net/)

### 2. *Clean Code* – Robert C. Martin  
![Clean Code](https://images-na.ssl-images-amazon.com/images/I/41jEbK-jG+L._SX374_BO1,204,203,200_.jpg)  
Aprenda a escrever código limpo e manutenível.  
📖 [Mais informações](https://www.amazon.com.br/C%C3%B3digo-limpo-Robert-C-Martin/dp/8576082675)

### 3. *Você Não Sabe JS* (You Don't Know JS) – Kyle Simpson  
![Você Não Sabe JS](https://d2sofvawe08yqg.cloudfront.net/ydkjsy-get-started/s_hero?1620621982)  
Série que aprofunda nos conceitos por trás do JavaScript.  
📖 [Mais informações](https://github.com/getify/You-Dont-Know-JS)


### 4. *Estruturas de Dados e Algoritmos em JavaScript* – Loiane Groner  
![Estruturas de Dados JS](https://imgv2-1-f.scribdassets.com/img/document/557618280/original/cfe258facc/1?v=1)  
Didático e em português, com foco em lógica, algoritmos e JS.  
📖 [Mais informações](https://www.casadocodigo.com.br/products/livro-estructuras-dados-algoritmos-javascript)

### 5. *Refatoração* – Martin Fowler  
![Refatoração](https://m.media-amazon.com/images/I/81sTm5M7wjL.jpg)  
Como melhorar o design do seu código sem quebrar nada.  
📖 [Mais informações](https://martinfowler.com/books/refactoring.html)

### 6. *Design Patterns em JavaScript* – Addy Osmani  
![Design Patterns JS](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQOONHZC6ewFb_x-qWCRsG_TWRNKRJGZwvuYQ&s)  
Um guia prático dos padrões de projeto no JS moderno.  
📖 [Leia online](https://addyosmani.com/resources/essentialjsdesignpatterns/book/)
